## Value or Theater? AI first drafts for Tier 1 billing tickets

| Question | Answer from the input | Grade |
|---|---|---|
| Whose problem? | Small-business owners waiting a median 19 h on billing questions | ✅ |
| What changes? | Agents review and send model drafts instead of writing from 14 macros | ✅ |
| Compared to what? | Today's macro-based replies; CSAT 3.1 vs 4.2 overall | ✅ |
| How would we know it failed? | Time to first reply, CSAT, unedited-send rate; stop if >10% of drafts have a billing error | ✅ |
| Who owns it when it's wrong? | Support Ops lead, reviewed weekly with Finance; nothing goes out unreviewed | ✅ |

### Verdict: 🎯 VALUE
### Move: PURSUE

A named customer, a real wait, a baseline, a stop rule, and an owner. Pursue the 4-week pilot it proposes, not a rollout.

### To keep it value
- Write the CSAT target down before the pilot starts.
- Count review time in "time to first reply," or the savings are imaginary.

---

**Why this is good:** every grade cites the input, the verdict comes with its move, and "pursue" is scoped to the pilot the evidence supports. There's no buzzword decoder because there are no buzzwords.
